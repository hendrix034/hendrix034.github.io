# Portfolio Website

A modern, responsive portfolio website built with Next.js, React, and Tailwind CSS.

## Features

- 🎨 Modern and clean design
- 📱 Fully responsive
- 🌙 Dark mode support
- ⚡ Fast and optimized
- 🎯 Smooth scrolling navigation
- 📧 Contact form
- 🚀 Easy to customize

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Customization

### Update Your Information

1. **Hero Section** (`components/Hero.tsx`):
   - Change "Your Name Here" to your actual name
   - Update the job title and description

2. **About Section** (`components/About.tsx`):
   - Replace the placeholder text with your own story

3. **Skills Section** (`components/Skills.tsx`):
   - Update the skills arrays with your actual skills

4. **Projects Section** (`components/Projects.tsx`):
   - Replace the placeholder projects with your actual projects
   - Update links and descriptions

5. **Contact Section** (`components/Contact.tsx`):
   - Update social media links
   - Change the email address
   - Customize the contact form handler

6. **Navigation** (`components/Navigation.tsx`):
   - Update the portfolio name/logo if needed

### Styling

The website uses Tailwind CSS. You can customize colors, spacing, and other styles by editing:
- `tailwind.config.ts` - Tailwind configuration
- Individual component files - Component-specific styles

## Build for Production

```bash
npm run build
npm start
```
